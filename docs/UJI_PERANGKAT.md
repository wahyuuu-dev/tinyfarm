# Daftar uji perangkat (centang satu per satu)

## Semua perangkat
- [ ] Game terbuka tanpa pesan merah di layar (pesan kesalahan akan tampil di atas layar bila ada).
- [ ] Menu: Game Baru, Pengaturan, Kredit berfungsi. Nomor versi tampil.
- [ ] Satu hari penuh dimainkan: jam berjalan, senja, malam, lalu tidur di rumah.
- [ ] Cangkul, tanam, siram, tidur, tanaman tumbuh (kamera menoleh ke tanaman, ada sinar), panen.
- [ ] Toko: beli benih, jual hasil. Tas (E / TAS) menampilkan isi.
- [ ] Suara terdengar setelah ketukan pertama; Musik dan Efek suara bisa dimatikan dan tetap setelah muat ulang.
- [ ] Simpan otomatis: tutup tab, buka lagi, Lanjutkan memuat hari, koin, tanaman, dan posisi yang sama.
- [ ] Menang (1.500 koin) dan kalah (hari 20 habis) menampilkan layar akhir.
- [ ] Karakter lewat gerbang pagar dengan mudah dan tidak bisa menembus pohon, air, rumah, kios.

## PC / laptop (Chrome, Edge, Firefox)
- [ ] Ubah ukuran jendela: pixel tetap tajam, tidak ada scroll.
- [ ] Tombol Layar penuh di Pengaturan berfungsi.
- [ ] Keyboard dan mouse (klik = aksi, roda = ganti alat).
- [ ] Penghitung FPS (Pengaturan) stabil sekitar 60.

## Android (Chrome)
- [ ] Mode portrait menampilkan layar "putar perangkat"; landscape memunculkan game.
- [ ] Joystick di kiri, tombol AKSI / ALAT / TAS / jeda di kanan tidak menutupi karakter.
- [ ] Joystick dan AKSI bisa dipakai bersamaan (multi-touch).
- [ ] Tidak ada zoom saat mengetuk dua kali, tidak ada halaman yang bergeser.
- [ ] Panel Toko dan Tas terlihat penuh atau bisa digulir; tombol nyaman diketuk.
- [ ] Tidak ada bagian yang tertutup lekukan layar (notch) atau bilah sistem.
- [ ] Pindah aplikasi lalu kembali: game terjeda dan suara berhenti/lanjut dengan benar.

## iPhone (Safari)
- [ ] Semua poin Android di atas.
- [ ] Suara baru berbunyi setelah ketukan pertama.
- [ ] Layar penuh tidak tersedia di iPhone (tombolnya otomatis disembunyikan); itu normal.
- [ ] Putar perangkat dari portrait ke landscape dan sebaliknya: tampilan menyesuaikan.

## Bila ada masalah
Catat: perangkat, browser, langkah yang dilakukan, dan tangkapan layar (termasuk pesan merah bila ada).
