# Kredit
- Kode, sprite pixel art, efek suara, dan musik latar: dibuat khusus untuk Tiny Farm Life.
- Sprite digambar lewat kode (JavaScript Canvas). Suara dan musik dibuat lewat Web Audio API.
- Tidak ada aset gambar, audio, atau font dari pihak luar. Jika kelak ditambahkan, catat sumber dan lisensinya di sini.
