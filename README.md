# Tiny Farm Life — Grow Small. Dream Big.
Game simulasi pertanian 2D pixel art (HTML5 Canvas, JavaScript tanpa library). Versi 1.0.0.

## Menjalankan
Buka folder ini di VS Code, klik kanan `index.html`, pilih **Open with Live Server**.
Jangan klik dua kali `index.html` (ES modules tidak berjalan dari `file://`).

## Kontrol
- PC: WASD/panah jalan, Spasi/Enter/F atau klik = aksi, 1-6 atau roda mouse = ganti alat, Q = alat sebelumnya, E = tas, Esc/P = jeda.
- HP (landscape): joystick di kiri layar, tombol AKSI, ALAT, TAS di kanan, tombol II untuk jeda.

## Tujuan
Kumpulkan 1.500 koin sebelum Hari 20 berakhir. Cangkul, tanam, siram, panen, jual di kios. Tidur di rumah untuk ganti hari. Atur tanaman berpasangan untuk Harmony Garden.
